═══════════════════════════════════════════════════════════════
  HOW TO GET YOUR ZEGOCLOUD CREDENTIALS (5 MINUTES)
═══════════════════════════════════════════════════════════════

STEP 1: GO TO ZEGOCLOUD CONSOLE
→ Open this link in your browser:
  https://console.zegocloud.com/

STEP 2: SIGN UP / LOGIN
→ Create a new account OR login if you have one
→ You can use Google/GitHub to sign up quickly

STEP 3: CREATE A PROJECT
→ Click "Projects" in the left sidebar
→ Click "Create Project" button
→ Enter project name: "Smart Health Care System"
→ Select your region (choose closest to you)
→ Click "Create"

STEP 4: GET YOUR CREDENTIALS
→ After creating project, you'll see the dashboard
→ Look for these two values:
  
  ┌─────────────────────────────────────┐
  │ AppID: 123456789                    │  ← This is a NUMBER
  │ ServerSecret: abc123def456...       │  ← This is a STRING
  └─────────────────────────────────────┘

STEP 5: UPDATE CONFIG.JSX
→ Open: frontend/src/Config.jsx
→ Replace the values:

  BEFORE:
  export const APP_ID = 65657576;
  export const SECRET = "YOUR_SECRET_KEY_HERE";

  AFTER (with your actual values):
  export const APP_ID = 123456789;  // Your AppID
  export const SECRET = "abc123def456ghi789jkl";  // Your ServerSecret

STEP 6: SAVE AND REFRESH
→ Save the Config.jsx file
→ Refresh your browser (F5 or Ctrl+R)
→ The error should be gone!

═══════════════════════════════════════════════════════════════
  IMPORTANT NOTES
═══════════════════════════════════════════════════════════════

✓ AppID is a NUMBER (no quotes)
✓ SECRET is a STRING (needs quotes "")
✓ Don't share your SECRET publicly
✓ Free tier includes 10,000 minutes/month

  NEED HELP?
═══════════════════════════════════════════════════════════════

If you see the same error after adding credentials:
1. Make sure SECRET is not empty
2. Make sure SECRET has quotes around it
3. Save the file and refresh browser
4. Check browser console for other errors
